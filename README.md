Using System stopwatch, the C++ plugin finished sorting 10000 integers in 0.5 ms, C# in 1.61 ms, and monobehaviour in 1.03 ms. 
The Native Plugins are useful and have a higher performance, showing why plugins can be used on small scales like this one.
When scaled up the small scale difference of roughly 1 MS ramps up across many different operations, and larger projects.
Using C++ to optimize in a C# project can be useful, but honestly was a much harder process to make and debug, even with AI assistance.
